## About

Arduino examples and IDE fixes for the **DFRobot UniHiker K10** — the ESP32-S3 based education board with built-in display, camera and sensors.

## Contents

| Folder | What's inside |
|--------|---------------|
| `Arduino Examples/` | `Digital_WiFi_Clock` and `Display_Showing_Text` sample projects |
| `Error-Fix/` | Patched `platform.txt` for the UNIHIKER board package — fixes the Arduino IDE compile path issue |

## Getting Started

1. Install the **UniHiker K10 board package** in the Arduino IDE
2. If builds fail with a path error, apply the fix from `Error-Fix/`
3. Open any example and upload

📺 Step-by-step tutorials are on our [YouTube channel](https://www.youtube.com/@Fusion_Automate).
